# 💡 Idées de Projets Web pour Débutants & Étudiants

Ce guide liste des projets concrets pour s'entraîner au HTML, CSS, JavaScript et React. Chaque projet aide à maîtriser une compétence spécifique.

---

## 🟢 Niveau 1 : Fondamentaux (HTML / CSS)

_Objectif : Maîtriser la mise en page, le Flexbox/Grid et le Responsive._

1. **Page de Profil / Linktree** : Une page simple avec ta photo, une bio et des boutons vers tes réseaux sociaux.
2. **Landing Page de Produit** : Une page de vente pour un objet imaginaire (Header, caractéristiques, prix, footer).
3. **Formulaire de Contact Moderne** : Créer un formulaire complet avec des validations visuelles (champs requis, types d'emails).
4. **Portfolio Statique** : Présenter tes futurs projets avec une galerie d'images et un CV en ligne.

---

## 🟡 Niveau 2 : Logique (JavaScript Vanilla)

_Objectif : Manipuler le DOM, les événements et les données._

1. **To-Do List avec LocalStorage** : Une liste de tâches où l'on peut ajouter, barrer et supprimer. Les tâches doivent rester même après avoir rafraîchi la page.
2. **Calculatrice** : Un classique pour gérer les opérations mathématiques et l'affichage des chiffres.
3. **Chronomètre / Timer** : Gérer le temps (`setInterval`) avec des boutons Start, Pause et Reset.
4. **Générateur de Citations** : Un bouton qui affiche une citation aléatoire provenant d'un tableau (ou d'une API simple).
5. **Quiz Interactif** : Un questionnaire avec calcul du score à la fin.

---

## 🟠 Niveau 3 : API & Dynamisme (JS Avancé / React)

_Objectif : Récupérer des données externes et gérer l'état (State)._

1. **Application Météo** : Utiliser l'API _OpenWeatherMap_ pour afficher la météo d'une ville tapée par l'utilisateur.
2. **Recherche de Films** : Utiliser l'API _OMDb_ pour afficher les affiches et les résumés de films.
3. **Pokedex** : Utiliser la _PokeAPI_ pour lister les Pokémon avec leurs types et statistiques.
4. **Dashboard de Crypto-monnaies** : Afficher les prix en temps réel via l'API _CoinGecko_.
5. **Convertisseur de Devises** : Calculer le taux de change entre deux monnaies en utilisant des données live.

---

## 🔴 Niveau 4 : Projets "Portfolio" (Fullstack ou React Complexe)

_Objectif : Créer une application complète et utile._

1. **Clone de Trello (Drag & Drop)** : Organiser des cartes dans des colonnes (À faire, En cours, Fait).
2. **Plateforme de Blog** : Un système où l'on peut lire des articles et les filtrer par catégorie.
3. **Site E-commerce (Frontend)** : Un catalogue de produits avec un panier d'achat fonctionnel (calcul du total).
4. **Messagerie en temps réel** : Utiliser Firebase ou Socket.io pour créer un petit chat entre amis.
